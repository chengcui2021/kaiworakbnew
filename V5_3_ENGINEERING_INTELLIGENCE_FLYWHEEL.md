# Kaiwora KB V5.3 — Governed Engineering Intelligence

V5.3 turns run outcomes into governed reusable engineering intelligence without allowing the Agent to approve itself.

- Every Agent observation is a tenant-scoped learning candidate and an OPEN normal KB entry.
- No automatic candidate -> authoritative transition. Human Resolve/approval remains the authority boundary.
- Candidate evidence records occurrence/reusability signals and success/failure provenance.
- `knowledge_usage` captures which approved entries participated in successful/failed runs, repair count, task type and relevance.
- Resolver V3 combines semantic relevance, lexical relevance and historical validated outcomes while preserving tenant/workspace/repository authorization.
- Cross-customer promotion remains sanitised and separately reviewed before creating global Approved Knowledge.
- Knowledge source taxonomy now includes manual/curated, Claude Skill, CLAUDE.md, AGENTS.md, architecture, validation playbook, coding standard, security policy, historical PR evidence, Confluence/Notion exports and extracted document text, plus GitHub and URL snapshots.
