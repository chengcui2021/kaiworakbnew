## Snapshot

metamorphic-kb had **zero** automated test coverage before Phase 8. Tiers are
P0 (critical path / shared foundation) → P1 (domain services) → P2
(display-only pages/components). Update this file as tests get added; don't
let it drift.

Suite: **89 unit tests across 9 files, all passing** (`cd frontend && npm run test:unit`)
plus a Playwright suite (`npm run test:e2e`) covering all 10 routes plus
tag-delete confirm, unsaved-changes guard, search-scope-toggle, markdown-split-editor
(Editor/Split/Preview mode switch + Mermaid diagram rendering),
edit-entry-form-organization, panel-toast-feedback, context-packages-discoverability,
entry-card/context-hash a11y, medical-device-poc step connector,
toast-and-persistent-alerts, zod-form-validation, document-list-table, and
tags-page-table journeys.

**Note:** `npm run build` runs `vue-tsc -b` (project-reference build mode), which is
stricter than the ad hoc `npx vue-tsc --noEmit` used for quick checks during a change —
it caught a real type error (`componentField['onUpdate:modelValue']` optional-call) that
`--noEmit` missed. Run a full `npm run build` before considering vee-validate/zod form
work done, not just `--noEmit`.
