# Kaiwora KB V5.2 — Governed Knowledge Flywheel

Admin KB is the governance plane for reusable engineering intelligence. Run-specific ticket, repository and transcript analysis happens in the Agent.

Knowledge sources now include GitHub repository snapshots, manually curated/pasted material, text-based documentation URLs, and automatic Agent-run learning candidates. Every source creates OPEN candidates; human Resolve remains the authority boundary.

The Agent can request approved `analysis-guidance` before Qwen performs transcript/requirement analysis. This lets approved knowledge improve epic/ticket/acceptance-criteria quality without moving runtime analysis into Admin KB.
