# Customer-approved contribution v4

Customer learning is tenant-private by default. Customer Knowledge Sources and Project Run evidence may create tenant-scoped candidates; customer review is required before reuse.

If the customer explicitly enables sharing in Agent Admin & Privacy, an approved candidate may be transformed into a sanitised Kaiwora KB Admin global-learning candidate. This does not export raw source documents, source code or unapproved observations. Kaiwora Admin performs a second review before master knowledge is created.
