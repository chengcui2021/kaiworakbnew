# Continue KB Phase 1 Architecture

## Target Stack
- Frontend: Vue 3 + TypeScript + Vite
- Backend: Python + FastAPI
- Runtime: Docker Compose

## Runtime Shape
The prototype is generated as a two-service web application. The frontend calls the FastAPI backend for health and domain data. Docker Compose provides a consistent preview runtime.

- Vue 3 + TypeScript Frontend
- Vite Dev Server
- FastAPI Backend
- Domain API Routes
